Excel Sales Dashboard
Project Overview
This project is an interactive Excel Sales Dashboard developed using Microsoft Excel. The dashboard helps analyze sales performance through visualizations, filters, and reports.
Objectives
- Analyze sales data effectively.
- Visualize total sales and product performance.
- Monitor sales trends over time.
- Support decision-making using interactive dashboards.
Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
Dashboard Features
- Sales Dashboard
- Product-wise Analysis
- Salesman-wise Analysis
- Date Filter
- Place Filter
- Product Filter
- Interactive Navigation
